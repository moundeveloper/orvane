Backups and restore

Operations · Revision 14

Fieldnotes keeps every notebook in one database file on this computer. A backup is a second copy of that file, taken while the app is running, together with the attachments folder.

Where backups live

By default, copies are written to the backups folder beside the database. You can point them at another drive in the settings file.

[backup]
directory = "D:/Backups/fieldnotes"
every = "1d"
keep = 14

The directory is created on the first run. If the drive is missing, the app reports the failure and tries again at the next scheduled time.

Schedule

Pick an interval that matches how much work you can afford to redo. A backup runs once a day while the app is open, using SQLite's online backup so that writes can continue during the copy. A run that was missed while the app was closed starts shortly after the next launch.

Large notebooks take longer to copy. Progress is shown in the status area, and closing the window waits until the current copy has finished.

Attachments are copied after the database. Only files that changed since the previous run are written again, so a daily backup of an unchanged library is close to instant.

Retention

The newest 14 copies are kept. Older copies are removed only after a new backup has been written and passed its integrity check, so a failed run never reduces the number of good copies you have.

Copies you rename are left alone. Use this to hold on to a snapshot from before a large import or a migration.

The integrity check opens the new copy read-only and verifies every table and index. A copy that fails is kept with a .failed suffix for inspection.

Restore

Restoring replaces the whole database, not individual notes. Close other windows first.

Choose a copy from the list and confirm. Before restoring, the app saves the current database as a safety copy named with the restore time. If the restored data is not what you expected, restore that safety copy.

After the restore the app restarts and rebuilds its search index. Searching works again once the rebuild is complete.

Moving to another computer

Copy the newest backup and the attachments folder to the new machine, then choose Restore on first launch. Settings are not part of the backup.
